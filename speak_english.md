Today, I'd like to introduce **Pinetree**, 
a web service I'm developing.
Pinetree is a web-based **hierarchical markdown editor**.
Let me explain in detail what "hierarchical" means.

The hierarchical concept is inspired 
by Amazon's "One Pager" culture.
"One Pager" is a style that concisely summarizes 
key points on a single page.
Everyone likes readable, short text. 
But detailed information is often necessary too. 
The point is how to resolve this contradiction.

Detailed documents are hard to read. 
On the other hand, when you split documents into files, 
the connections between files become hard to see.
You can express parent-child relationships using folders, 
but it becomes difficult to naturally link documents together.
Including parent file names in child files 
or being conscious of hierarchical structure 
makes it somewhat clearer, 
but there are still limitations at the file unit level.

Pinetree allows you to organize 
the text itself in a hierarchical structure.
Being web-based, navigation through links is also smooth.
For readers too, structural connections 
can be intuitively understood.

Pinetree is optimal for documents that require 
both "conciseness" and "detail," 
such as travel plans, resumes, and reading notes.
Each section starts with a One Pager-style 
concise summary, 
with detailed hierarchies added below.
This way, even detailed documents become One Pagers. 
By repeating this, the entire hierarchy 
is summarized into short text, 
creating a readable hierarchical document structure.

I love markdown. 
Especially the style where "left input field, 
right preview" can be viewed simultaneously is ideal.
When you have to open preview in a separate screen 
like GitHub, I feel it's inconvenient to use.
Even if you can write in a markdown-like style 
like Google Docs or Notion, 
it's inconvenient if you can't export as markdown.

For example, when you input "-" or "1." 
and press enter, 
I want symbols to automatically appear 
on the next line too.
I want the tab key to be fixed to two spaces.
Since I don't remember all markdown syntax, 
it would be helpful to insert intuitively 
from a toolbar.

I want images to be displayed in preview immediately 
just by copy-paste or drag & drop.
Since there are accidental operations, 
UNDO/REDO functionality is essential.
If emojis could be used too, it would be more fun.

All the basic features introduced so far 
have already been implemented, 
and hierarchical structure is also supported.
There are various tools that can do similar things, 
but I haven't found one that 
**"can do everything I want to do!"**
Pinetree isn't perfect yet, 
but it's a markdown editor that has 
the minimum essential elements I need.

When I actually used it, 
I felt that hierarchical text is surprisingly useful 
in many situations.
The more you write, 
the longer text tends to become vertically, 
but by organizing it structurally, 
you can reduce the amount you read at once.
By dividing into "chapters" or "by topic," 
readers' understanding also becomes smoother.

It's also suitable for things that can't necessarily 
be written in order, like travel planning.
Plans often change while writing.
When information comes together, 
you can organize it hierarchically as "chunks."

It has good compatibility with things recorded by date, 
like blogs.
Since you don't necessarily write every day, 
the way you organize changes 
depending on how much you write.
Depending on how much you write, 
you can organize hierarchically by week or month, 
or manage 12 months within one file.

There's no single "correct answer" 
for readable document structure.
The optimal hierarchy changes 
depending on purpose and amount of information.
Whether to make parent-child relationships 
or sibling relationships - 
this flexibility is a major strength 
of hierarchical structure.
